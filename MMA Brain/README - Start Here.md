# 🥋 MMA Brain — Start Here

**Open [[MMA.canvas|the master MMA Canvas]]** in `01 Maps`. Tap any discipline map to drill down through fundamentals, warm-ups, positions, techniques and applications.

## Workflow
1. At the gym, jot down a cue or problem in your pocket notebook.
2. After class, paste it into [[Quick Capture]] or create a note using [[Practice Template]].
3. Link techniques using `[[note name]]`. Open any discipline Canvas to browse its progression.
4. Add videos with [[Video Source Template]] and store links/timestamps, not giant media files.
5. Track failures in [[Problem Tracker]] and status in [[Progress Dashboard]].
6. Weekly: process inbox, choose one drill priority, update outcomes.

## How the maps work
- Master MMA map → each discipline `.canvas` (file cards)
- Discipline map → foundation and progression notes (file cards)
- Cross-art relationships → `[[wikilinks]]` and Obsidian Backlinks/Local Graph
- The example structure is a **starter curriculum**, not a claim of universal technique order.
- Book index reflects the uploaded book's visible table of contents, not a full transcription.

## iPhone
Import the entire `MMA Brain` folder into your Obsidian vault using Files, or extract this ZIP into the vault's folder. Keep the directory structure intact. Tap a file card in Canvas to open its linked note or sub-canvas.

## GitHub sync
Keep your private repo for Markdown, Canvas and small images; keep large videos in external storage. Test sync on one device before editing simultaneously on two.
