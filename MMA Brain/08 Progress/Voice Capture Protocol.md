# Voice capture → progress review protocol

After each session, speak naturally. Useful details: actual date, art, position or technique, opponent's reaction, what worked, what failed, whether the round was drilling, positional or live, approximate attempts/successes, and next test.

1. Append the verbatim capture to `00 Inbox/Quick Capture.md` or a dated session note. Never delete or rewrite it.
2. Extract observations into a review proposal. Preserve uncertainty, especially dates, opponents, and results.
3. Link existing techniques by stable note path; avoid duplicate technique notes.
4. Append dated evidence to technique progress notes. A claim of improvement is not a confirmed resolution.
5. Recalculate proficiency only when enough comparable evidence exists; show unknown otherwise.
6. Validate all `.canvas` JSON, unique node IDs, edge endpoints, and referenced files before proposing canvas changes.
7. Create a draft pull request for review; never auto-merge, overwrite manual layouts, or delete captures.
8. Obsidian phone-to-GitHub sync is a separate process from weekly GitHub Actions processing.

## Review questions
When did I last practice it? What failed? What correction did I try? Did it work against resistance? Did the improvement persist? What is my next test?
