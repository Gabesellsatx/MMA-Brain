# MMA Brain

An open-source martial arts knowledge base built with Obsidian.

## Disciplines
- Brazilian Jiu-Jitsu
- Wrestling
- Judo
- Muay Thai
- Boxing
- Kickboxing
- MMA Integration
- Strength and Conditioning
- Mobility and Physical Therapy

## Purpose
Build an interconnected library of martial arts fundamentals, techniques, drills, and visual Canvas maps.

## Collaboration
Friends and martial artists can contribute knowledge through GitHub pull requests.
